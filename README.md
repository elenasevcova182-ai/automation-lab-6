# automation-lab-6

Описание проекта

Учебный проект в рамках лабораторной работы №6 по дисциплине
«Внедрение и поддержка компьютерных систем».

Тема: Автоматизация процессов внедрения и поддержки компьютерных систем.
Практическое использование онлайн-инструментов для автоматизации
развёртывания и управления конфигурациями.

Цель работы: освоить методику автоматизации процессов внедрения и
поддержки компьютерных систем, научиться применять современные подходы
(CI/CD, контейнеризация, управление конфигурациями) для автоматизации
развёртывания, мониторинга и сопровождения внедрённых систем.

Изучаемые темы

1. Автоматизация процессов внедрения и поддержки компьютерных систем
2. Непрерывная интеграция и непрерывное развёртывание (CI/CD)
3. Контейнеризация приложений (Docker)
4. Управление конфигурациями и инфраструктура как код (IaC)
5. Онлайн-инструменты автоматизации развёртывания и мониторинга
